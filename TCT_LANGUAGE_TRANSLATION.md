# TCT Terminology Translation Guide

## Purpose

This document maps project-specific TCT terminology onto terminology commonly used in fusion, plasma physics, reduced-MHD, edge-stability, and disruption-mitigation literature.

The goal is communication clarity.

The mappings below do not imply physical equivalence. They identify the closest established language for discussing the same hypotheses.

---

## Preferred external wording

Avoid:

- TCT stabilizes plasma
- TCT eliminates ELMs
- TCT solves reconnection
- Lithium current stabilizes the edge

Prefer:

- TCT-inspired control strategy
- Edge-current-profile modification
- Current-sheet broadening proxy
- Reconnection-mitigation proxy
- Event-severity-reduction strategy
- Precursor-triggered control strategy
- Candidate edge-control actuator

## Current repository position

The repository does not claim that TCT has been experimentally validated.

The current claim is:

> A TCT-inspired edge-control strategy is being evaluated through reduced-order event-severity, precursor-response, and current-profile proxies while blanket concepts are screened through OpenMC-based neutronics workflows.

This language should be preferred in publications, outreach, README text, issue discussions, and external reviews.
